# 🎨 @plantifiles/ui

Shared React components for the web app. shadcn-style: Radix primitives, CVA variants, Tailwind 4.

---

</div>

Button, dialog, dropdown menu, tabs, popover, select, tooltip, textarea, input, badge, alert dialog, checkbox, label, empty state, and a few hooks and helpers.

Exported straight from source (`./components/*`, `./hooks/*`, `./lib/*`) — no build step, the app compiles it.

## ➕ Adding a component

```bash
pnpm exec shadcn add <component>
```

Run from this directory (there's a `components.json`), then adjust to the house style.
